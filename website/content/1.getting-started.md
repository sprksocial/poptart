## Start With The Umbrella Package

Use `poptart` for normal application code. It re-exports the app-facing client,
core request/session types, OAuth helpers, XRPC utilities, and common AT
Protocol primitives. Add `poptart_lex` when you want generated method
descriptors or generated record models for `com.atproto.*`; add the matching
generated package for other lexicon namespaces.

```sh
dart pub add poptart
dart pub add bluesky_poptart
```

```dart
import 'package:poptart/poptart.dart';
```

For apps that only make raw XRPC calls, `poptart` can be the only dependency.
For typed calls, import the exact generated descriptor barrel from the package
that owns that namespace. Use `poptart_lex` for `com.atproto.*`,
`bluesky_poptart` for `app.bsky.*` and `chat.bsky.*`, `ozone_poptart` for
`tools.ozone.*`, `sprk_poptart` for `so.sprk.*`, and `margin_poptart` for
`at.margin.*`.

## Make An Anonymous Request

Public AT Protocol endpoints can be called without a session. Use the generated
method descriptors when you want typed inputs and outputs.

```dart
import 'package:poptart/poptart.dart';
import 'package:bluesky_poptart/app/bsky/actor/get_profile.dart'
    as get_profile;

Future<void> main() async {
  final client = PoptartClient.anonymous();

  final response = await client.call(
    get_profile.appBskyActorGetProfile,
    parameters: const get_profile.ActorGetProfileInput(
      actor: 'bsky.app',
    ),
  );

  print(response.data.displayName);
}
```

Generated method barrels are named after lexicon IDs. For example,
`app.bsky.actor.getProfile` is exported from
`package:bluesky_poptart/app/bsky/actor/get_profile.dart`.

The generated method value is the friendly default. If you prefer the explicit
descriptor style, `client.call(get_profile.methodDescriptor, ...)` works too.

## Create A Password Session

App-password flows are useful for scripts, prototypes, and server-side jobs. For
user-facing mobile or web apps, prefer OAuth.

```dart
import 'package:poptart/poptart.dart';
import 'package:bluesky_poptart/app/bsky/feed/get_timeline.dart'
    as get_timeline;

Future<void> main() async {
  final session = await createSession(
    identifier: 'alice.example.com',
    password: 'app-password',
  );

  final client = PoptartClient.fromSession(session.data);
  final timeline = await client.call(
    get_timeline.appBskyFeedGetTimeline,
    parameters: const get_timeline.FeedGetTimelineInput(limit: 25),
  );

  for (final item in timeline.data.feed) {
    print(item.post.uri);
  }
}
```

Keep the returned `Session` somewhere secure if your app needs to reuse it.
Refresh it with `refreshSession(refreshJwt: session.refreshJwt)` before the
access token expires.

## Use A Different Service

Poptart defaults to the public Bluesky AT Protocol services, but clients accept
service overrides for self-hosted PDSs, test services, and relay-specific work.

```dart
final client = PoptartClient.anonymous(
  service: 'https://example-pds.test',
  relayService: 'https://example-relay.test',
);
```

Pass `service` on a single call when only one request needs to go somewhere
else:

```dart
final response = await client.get<Map<String, dynamic>>(
  NSID.parse('com.atproto.identity.resolveHandle'),
  service: 'https://another-pds.test',
  parameters: {'handle': 'alice.example.com'},
);
```
